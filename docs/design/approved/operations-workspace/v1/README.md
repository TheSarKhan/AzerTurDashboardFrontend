# Operator sorğu paneli — təsdiqlənmiş v1

İstifadəçinin son göndərdiyi şəkil əsasdır. v2 sağ detal paneli seçilməyib.

Tətbiq: EN/RU/AZ, məlumatlar operations API-dən gəlir. Saylar uydurulmur. Səfərin son tarixi saxlanmadığından yalnız mövcud başlanma tarixi göstərilir. Gələcək səfərlər təsdiqlənmiş rezervasiyaların növbəti 7 gündəki başlanmasıdır. Prioritetlər uyğun siyahını süzür, fəaliyyət qeydləri faktiki auditdən gəlir. Məbləğ valyutası filtri yoxdur, çünki cədvəldə məbləğ yoxdur. Cari ofis hesabı özünə təyinat edə və buraxa bilər; çoxsaylı əməkdaş hesablarının idarəsi ayrıca mərhələdir.

Əsas düymə əvvəl sorğu seçilməsini tələb edir və seçilmiş sorğunun növbəti addımına aparır. Tək seçim müştəriyə təklif göndərmir. Mövcud detallar və qaralama/önizləmə/göndərmə addımları qorunur.

Partnyorların idarəsi ayrıca təsdiqlənəcək modul olaraq qalır; işləməyən naviqasiya əlavə edilməyib.
